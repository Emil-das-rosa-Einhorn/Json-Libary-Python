# JSON Library Tools

A collection of lightweight terminal-based utilities to efficiently manage, edit, and validate JSON structures and typemaps directly from your console.

---

## Included Tools

### 1. JSON Editor & Validator
**Status:** `In Development` 
A feature-rich TUI (Terminal User Interface) built with `Textual` (Copyright (c) 2021 Will McGugan) that lets you navigate complex JSON structures seamlessly.

*   **Tree Navigation:** Visualize your JSON structure as an interactive tree.
*   **Live Filtering:** Quick search bar to filter keys instantly.
*   **In-Place Editing:** Modify key-value pairs and instantly configure structural Typemap rules (Type, Allow, Content, Default).
*   **Responsive Safeguards:** Built-in screen warning if your terminal window drops below the required dimensions.

### 2. Typemap Checker
**Status:** `Coming Soon` 
An automated validation tool to scan your generated typemaps for structural errors, type mismatches, and logical inconsistencies.
